# 📝 Simple Blog Post UI
This is a clean and responsive blog post component built using HTML5 and CSS3.

It displays a featured image, a short description, and a “Read More” button in a structured and minimal layout.
The goal of this project was to practice layout structuring, styling components, and creating reusable blog sections using pure CSS.

## ✨ Features

- Blog card layout

- Featured image section

- Short preview description

- Styled "Read More" button

- Clean and modern UI

- Responsive design

- Built with pure HTML & CSS

- Lightweight and fast loading

## 🧩 Project Structure
### 🖼️ Image Section
Displays a featured blog image at the top.
### 📄 Description Section
Shows a short summary of the blog content.
### 🔘 Read More Button
A clickable button that can link to a full blog post page.

## 🛠️ Built With

- HTML5

- CSS3

No frameworks. No libraries. Just core web fundamentals.

## 🎯 Purpose of This Project
### This project was created to:
- Practice structuring content using semantic HTML

- Improve CSS styling skills

- Learn button and card design

- Understand spacing and layout control

- Build reusable blog components
